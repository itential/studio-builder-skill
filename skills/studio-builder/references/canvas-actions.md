# Canvas Actions

Screenshot before and after every action.

## Select a task
`Esc` until no panel is open → `Q` → type the task name → `Enter`.

## Add a task after the selected task
`⇧T` → type the task name → `↓` / `↑` to the right entry → `Enter`.
The new task is placed to the **right** of the selected one and connected.
Then move it into the column: `⇧↓` (about 10 times) → `⇧←` until aligned → screenshot.

## Add an error or failure path
Select the source task → `C` → arrows to the target → `E` or `F` → `Enter`.

## Connect two tasks
Select the first task → `C` → arrows to the second → `S` → `Enter`.

## Remove a task and keep the flow joined
Select the task → `⇧⌫`.

## Fill a task
Select the task → `Enter` → fill the fields → `Esc`.

## Call a child workflow
Add `childJob` → `Enter` → pick the child workflow → set variables or `data_array` → set loop type (empty, `sequential` or `parallel`) → `Esc`.

## Save
`⌘S` → screenshot the validation icon.

## Run
`⌘S` → `⇧R` → fill inputs → start → screenshot the result.

## Tidy (vertical layout)
`9` → screenshot → select any task off its column → `⇧` + arrows to line it up → screenshot.
Main path in one column, top to bottom. Error paths in a side column.
